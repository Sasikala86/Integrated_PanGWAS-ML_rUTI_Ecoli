# processed/

This directory contains intermediate data generated by the pipeline.

Typical files include:

- phenotype CSV files
- unfiltered ML matrices
- 1–99% prevalence-filtered ML matrices
- Chi² results
- mutual-information results
- Boruta selected/tentative/rejected feature lists
- STRICT and RELAXED integrated feature lists
- feature-overlap plots

These files are generated by the numbered scripts and are not required to be manually created before running the pipeline.
