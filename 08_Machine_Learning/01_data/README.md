# data/

Place the three input pangenome matrices used by the ML_Accessory workflow in this directory:

```text
gene_presence_absence_chromosomes.Rtab
gene_presence_absence_Plasmids.Rtab
gene_presence_absence_combined.Rtab
```

These files are read as tab-separated matrices with the first column used as the row index.

The repository intentionally does not include the raw pangenome data due to its large size.
